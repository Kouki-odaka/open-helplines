## Columns explained

| Column | Description |
|--------|-------------|
| **Name / Handle** | Real name or social handle — do not include email here if this file is public |
| **Platform** | Where you're sending the message (Discord, Slack, X DM, email, etc.) |
| **Type** | See candidate profile table in the EN outreach template |
| **Template** | Which template to use (A / B / C, EN or JA) |
| **Sent?** | ☐ = not sent, ✅ = sent, 🔁 = follow-up sent |
| **Response** | ⭐ = Starred, 💬 = Responded with feedback, ❌ = declined / no response |
| **Notes** | Free text — feedback summary, follow-up date, etc. |

## Selection criteria (aim for diversity)

- [ ] At least 4 AI / LLM developers
- [ ] At least 2 people with public developer audiences (Twitter/X, newsletter, etc.)
- [ ] At least 1 person who has worked in or closely with community services
- [ ] At least 2 Japanese-language contacts (for JA version metrics)
- [ ] Mixture of close friends and warm-but-professional acquaintances

---

## Day 1 checklist

- [ ] All 8–12 rows filled in (Name + Platform + Template)
- [ ] Messages personalised (no copy-paste bulk sends)
- [ ] All sent within first 24 hours of repo going public
- [ ] Follow-up reminder set for 3–5 days after send date
- [ ] Responses logged in this file

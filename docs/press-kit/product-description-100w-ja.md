# プロダクト説明 — open-helplines（100語、日本語）

**open-helplines** は、世界各国の精神的健康危機相談窓口（ホットライン）を集めたオープンソースデータベースです。CC0 パブリックドメインで公開されています。

MCP（Model Context Protocol）サーバーとして提供されており、Claude などの AI アシスタントが、どこにいる誰に対しても、適切な危機相談番号を即座に案内できます。すべてのレコードは公式情報源に基づいてコミュニティが検証済み。E.164 形式の電話番号、営業時間、対応言語タグを完備しています。

開発者は npm 一発で導入。臨床家や NGO は無料で活用。危機の瞬間に、オープンデータを。

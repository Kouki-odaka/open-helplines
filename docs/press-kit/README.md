## Logo Usage Guidelines

- **Do** use the logo at any size ≥ 48 px height
- **Do** use on light or dark backgrounds (use the matching `-light` / `-dark` variant for clarity)
- **Do not** recolor, rotate, or distort the logo
- **Do not** place the logo on backgrounds that reduce contrast below WCAG AA

# Product Description — open-helplines (100 words, English)

**open-helplines** is an open-source database of verified mental health crisis helplines spanning multiple countries, published under a CC0 public domain dedication.

It ships as an MCP (Model Context Protocol) server so AI assistants like Claude can instantly surface the right crisis number for any person, in any language, anywhere. Every record is community-verified against official sources, with E.164 phone numbers, operating hours, and language tags.

Developers embed it in apps with one npm install. Clinicians and NGOs query it for free. Crisis moments deserve open data—no paywalls, no gatekeepers, no vendor lock-in.

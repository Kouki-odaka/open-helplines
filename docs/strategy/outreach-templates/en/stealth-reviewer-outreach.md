# Stealth Reviewer Outreach Template (English)

> Usage: Send to **8–12 trusted peers** on Day 1 (first day the repo goes public).  
> Goal: First Stars, early GitHub activity, and quick feedback before the public launch.  
> Personalise every `[BRACKET]` before sending.

---

## Who to send this to

Target profile (aim for a mix):

| Type | Why they're valuable |
|------|---------------------|
| AI / LLM developer | Will actually install the MCP, give technical feedback |
| Open-source contributor | Familiar with GitHub contribution norms, likely to Star |
| Developer with public profile | Early Stars visible to their followers |
| Person with community focus | May share with their network |

Fill in your candidate list: see [`stealth-reviewer-candidates.md`](../../../marketing/stealth-reviewer-candidates.md)

---

## Template A — Developer / AI researcher (Discord DM, Slack, or email)

**Subject (email):** Quick favour — trying something I've been building quietly

---

Hey [Name],

Hope you're doing well! I've been working on something for the past few weeks and just went public today. Would love your eyes on it before the broader launch.

**The project:** open-helplines — an open-source, CC0-licensed registry of verified support-line contact records, distributed as an MCP server.

**The one-line pitch:** Claude and other AI assistants hallucinate phone numbers when asked about support services. This fixes that — verified data, zero API key, zero lock-in.

**Repo:** https://github.com/Kouki-odaka/open-helplines

---

If you have 5 minutes:

1. ⭐ Star the repo (even just that helps)
2. Try it: add to your `claude_desktop_config.json` and ask Claude for support lines in any country
3. If anything feels off — docs, schema, MCP behaviour — reply here. I want real feedback before the wider push.

No obligation to do anything beyond a quick look. I just trust your judgment and wanted you to be among the first to see it.

Thanks! — Koki

## Template C — For people with technical community audiences

> Use for people with newsletters, active Twitter/X, or Discord server audiences.  
> Add this paragraph **after** Template A's main body:

---

If it resonates with you and you feel like sharing with your audience at any point — even a passing mention — that would mean a lot. No pressure at all, just wanted you to know it exists before the public noise.

---

## Timing

- Send all 8–12 messages **within the first 24 hours** of going public
- Follow up once (3–5 days later) if no response — **one follow-up only**
- Do not send bulk messages; personalise each one

---

## Follow-up template (3–5 days later)

> Only send if no response to the first message.

---

Hey [Name] — following up on my note from [Day]. No worries if it's not the right time. If you do get a minute, the repo is at https://github.com/Kouki-odaka/open-helplines — even a Star helps early on.

Thanks either way! — Koki

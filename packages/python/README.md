# open-helplines (Python)

Python client and data models for the [open-helplines](https://github.com/Kouki-odaka/open-helplines) global mental health hotline registry.

## Installation

```bash
pip install open-helplines
```

## Usage

```python
from open_helplines import models

# Load and use helpline data
```
